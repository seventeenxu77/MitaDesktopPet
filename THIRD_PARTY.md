# Third-party boundaries

This repository is an integration overlay and does not vendor the following projects or assets.

- GPT-SoVITS: <https://github.com/RVC-Boss/GPT-SoVITS>
- Codex CLI and App Server: <https://developers.openai.com/codex/>
- Unity runtime/editor: distributed under Unity's applicable terms
- MiSide game assets and character material: not included; users must provide assets they are authorized to use

The absence of a file from this repository does not imply that it is freely redistributable. Review every upstream license and the rights for character, voice, model and training data before publishing a binary package.
